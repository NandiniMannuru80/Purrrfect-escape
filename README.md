Purrrfect Escape is a 2D platformer game developed using Unity and C#. Play as a cat, jump across platforms, dodge dangerous dog spike traps, and reach the finish flag to complete the level!

*****************************
🎮 About the Game

The goal is simple: guide your cat through the level, avoid the dog spike traps, and make it safely to the finish flag. Be careful with every jump!

✨ Features

🐱 Cat player with movement controls

🦘 Jump mechanics

🐶 Dog spike traps that send the player back to the starting position

🏁 Finish flag and level completion message

🎮 2D platformer gameplay

⚙️ Physics and collision detection using Unity

🕹️ Controls

Key

Action

A

🛠️ Built With

Game Engine: Unity

Programming Language: C#

Physics: Unity 2D Physics (Rigidbody2D, Collider2D)

Development Tools: Unity Editor and Visual Studio / Visual Studio Code

********************************************

🚀 How to Run

Clone or download this repository.

Open Unity Hub.

Click Add Project from Disk and select the downloaded project folder.

Open the project using a compatible Unity version.

Open the main game scene.

Press Play to start playing!
